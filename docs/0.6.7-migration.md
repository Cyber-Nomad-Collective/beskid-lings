# Moving beskid-lings to Beskid 0.6.7

Workarounds that exist only because of Beskid 0.6.6. Remove each one after a
0.6.7 preview is installed and the item is confirmed.

## Runner

- `Checker.bd`: `Invoke` runs `beskid` through `/bin/sh -c '...; echo "@exit $?"'`
  because `Process.Run` did not search `PATH` and dropped stdout on a non-zero
  exit. 0.6.7: `Process.Run("beskid", ...)` searches `PATH` and returns
  `Ok(output)` for any exit code; read `output.exitCode`. Error text comes from
  `Process.Message(error)`.
- `Editor.bd`: same `/bin/sh` use is fine (it runs a shell script on purpose).
- `Watch.bd`: the session loop runs in a spawned fiber that `Main` joins,
  because `Channel.Receive` in `Main` returned `Closed`. 0.6.7: `Receive`
  parks in `Main`; the extra fiber can go. Check whether `Core.Process.Exit`
  after the loop is still needed for the stdin fiber.

## Language

- Fields end with `;` instead of `,` (owner ruling). Apply the same automated
  rewrite that 0.6.7 uses for corelib and the Book to `exercises/`,
  `solutions/` and `Runner/`.
- Compound assignment (`+=`, `-=`, `*=`, `/=`, `%=`) works: remove the note in
  `exercises/08_collections/README.md`.
- `move` only at isolate crossings (owner ruling B): rewrite exercises 10-12
  (`lists1`, `move1`, `exchange1`). Collections mutate in place
  (`items.Push(x);`). Move the ownership lesson to the isolates exercises.
- Conditional expression `cond ? a : b` (owner request): consider a control
  flow exercise for it.
- Network and channel waits park in `Main` too: `network1` and `fibers1` may
  drop the `spawn` + `Join` wrapper around the scenario; keep one exercise
  that shows a fiber on purpose.

## Known 0.6.6 bugs the exercises work around

- Generic inference from an array literal of plain numbers (ICE): `generics1`
  uses a typed array variable.
- `==` on a `for ... in` value inside a generic function: `generics1` uses an
  index loop.
- A user generic method named `Push`: `generics2` uses `Bag<T>.Add`.
- Host hooks (`startup`, `init`, `dispose`) do not run: `hosts1`/`hosts2`
  teach only compile-time wiring. When hooks run, add an exercise that uses
  an injected service.

## Editor

- `.vscode/settings.json`: drop the TEMPORARY `"[beskid]": { "editor.formatOnSave": false }`
  once the formatter keeps leading comments; then reformat everything to the
  ruled style (braces on their own line, parenthesized conditions) with
  `beskid fmt`.
- The `obj/` and `Project.lock` watcher exclusions become harmless (the
  extension excludes `obj/` itself); keep or remove.
