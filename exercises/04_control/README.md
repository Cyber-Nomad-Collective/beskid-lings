# Control flow

- `if condition { ... } else if other { ... } else { ... }` picks one branch.
  The condition needs no parentheses and must be a `bool`.
- `while condition { ... }` repeats while the condition holds.
- `for i in range(start, end) { ... }` counts from `start` up to, but not
  including, `end`. `range(1, 4)` gives 1, 2 and 3.
